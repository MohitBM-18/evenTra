# 🏛️ evenTra — Smart Venue Management System
### Christ University Auditorium Booking Platform

**A modern, Gen-Z styled mobile application for booking auditoriums and venues at Christ University.**

---

## ✨ Features

- **Dark Mode First** — Frosted glass card UI with purple → cyan gradients.
- **Role Selection** — Login as Student Coordinator, Teacher, Department Admin, or Super Admin.
- **Explore Venues** — Search & filter auditoriums by Block and capacity.
- **Request Bookings** — Fill booking requests with equipment dependencies.
- **Manage Requests (Admin)** — Approve or reject requests dynamically.

---

## 🚀 Getting Started

1. **Get Dependencies**:
   ```bash
   flutter pub get
   ```
2. **Run App**:
   ```bash
   flutter run
   ```
